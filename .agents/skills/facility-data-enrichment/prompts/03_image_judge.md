# 프롬프트 3 — 이미지 판정기

당신은 장사시설 상세 페이지에 올릴 **사진의 적합성**을 판정합니다. 이미지를 보고 아래 JSON 만 출력하세요.

## 입력
- 이미지 (또는 URL), 시설 정보 `facility`, 출처 `source`, 이미 있는 이미지 개수

## 출력 (이미지당 1객체)
```json
{ "url": "...", "label": "전경", "label_conf": 0.9, "width": 1600, "height": 1000, "license": "official", "reason": "정문과 건물 전체가 보이는 전경" }
```

## label (하나만 선택)
**좋은 라벨** — 사이트에 쓸 수 있음
- `전경` 건물/단지 전체 · `봉안실` 안치 공간 내부 · `묘역` 묘지/잔디 구역 · `수목장` 수목·산책로
- `시설내부` 로비·추모실·제례실 · `추모관` 건물 외관/입구 · `진입로` 주차장·입구·도로 · `편의시설` 화장실·휴게·매점

**나쁜 라벨** — 반려
- `지도` 지도 캡처·약도 · `로고` 로고/간판만 · `인물` 얼굴이 크게 나온 사진(초상권) · `텍스트배너` 문구 위주 배너/이벤트 · `가격표` 가격표 이미지(이건 이미지 대신 가격 추출로 보낸다) · `기타` 판단 불가/무관

## 판정 규칙
1. **인물**: 얼굴이 식별 가능하게 크게 나오면 `인물`. 멀리 있는 방문객이 작게 찍힌 정도는 허용.
2. **개인 정보**: 위패·명패·묘비에 *실명이 읽히면* `기타`(반려) — 유족 개인정보. 흐려 읽을 수 없으면 허용.
3. **품질**: 800×500 미만, 심하게 흐림/어두움/과도한 보정 → `label_conf ≤ 0.4` (스크립트가 반려).
4. **워터마크/타사 로고**: 타 업체·플랫폼 워터마크가 있으면 `기타`.
5. **다른 시설 사진 의심**: 입력 시설과 무관해 보이면 `기타`, `reason` 에 의심 근거.
6. **중복**: 같은 장면의 크롭/해상도 차이는 가장 큰 1장만 남기고 나머지는 제출하지 않는다.

## license (출처에 따라 결정 — 이미지를 보고 판단하지 말 것)
- 시설 **공식 홈페이지** 에 시설이 직접 올린 사진 → `official`
- **공공누리** 등 이용허락 문구를 페이지에서 확인 → `public` (`reason` 에 문구 인용)
- 네이버·카카오·블로그·카페·뉴스·중개사이트(명당가/첫장/고이장례) → **`none`** (참고용. 반영 불가)
- 확인 못 하면 `none`.
