## 📌 오늘 작업 요약
챗봇 기능 고도화 + UI/UX 버그 수정 (총 2커밋)

## 1. 챗봇 — 시설 ID 노출 제거
- **문제**: 챗봇 답변에 `Id-파크0004` 같은 내부 시설 ID가 노출됨
- **수정 파일**: `app/api/chat/route.ts`
- **수정 내용**:
  - 시스템 프롬프트에 "ID, 내부코드 답변 노출 절대 금지" 규칙 강화
  - 시설 데이터를 AI에게 전달할 때, ID를 별도 `[내부코드: xxx — 답변에 절대 노출 금지]` 줄로 분리
  - ID는 시설 상세페이지 URL 생성에만 사용

## 2. 챗봇 — 가격 검색 로직 전면 재설계
- **문제**: "500만원대 경기도 봉안당" 검색 시 2만원대 시설이 나옴
- **원인**: `priceRange.min` (최저가 1개)만 비교하는 단순 로직
- **수정 파일**: `app/api/chat/route.ts`
- **수정 내용**:
  - `standardizedPrices` 내 모든 `rows`를 탐색하여 실제 가격 매칭
  - "X만원대" → 목표가격 ±30% 범위 검색, 결과 적으면 ±50%로 확대
  - "X만원 이하/이상" → 정확한 상한/하한 필터
  - 관리비(`MAINTENANCE`) 가격 계산에서 제외
  - 정렬: 목표가격 근접도순 (가장 가까운 가격의 시설 먼저)
  - **추천서 모드**: 가격 검색 시 코드에서 `✅ 예산 매칭 상품` 미리 분류 → AI는 가격을 변형 없이 전달만

## 3. 챗봇 — 지역 필터 버그 수정
- **문제**: "제주" 검색 시 "충청북도" 시설이 나옴
- **원인**: 
  - `allText`에 AI 응답 히스토리까지 포함 → AI가 이전에 "충북" 언급하면 오염
  - `regionKeywords` 배열에서 `충북`(index 10)이 `제주`(index 16)보다 앞이라 먼저 매칭
- **수정 파일**: `app/api/chat/route.ts`
- **수정 내용**:
  - 지역 추출: 현재 메시지 우선 → 사용자 이전 메시지만 검색 (AI 응답 제외)
  - `regionFullNames` 매핑 추가: `제주→제주특별자치도`, `충북→충청북도`, `경기→경기도` 등
  - 세부지역(시/군/구)도 동일한 사용자 메시지 우선 로직 적용

## 4. 챗봇 — 가이드 셀링 퍼널 선택지 추가
- **수정 파일**: `app/api/chat/route.ts` (시스템 프롬프트)
- STEP 1 시설유형: `봉안당|수목장|잘 모르겠어요` → `봉안당|수목장|묘지|잘 모르겠어요`
- STEP 2 지역: `서울|경기|인천|기타 지역` → `서울|경기|부산|제주|기타 지역`

## 5. 챗봇 FAB — 말풍선 위치 변경
- **문제**: "장지 비교·추천 맞춤 상담 도와드려요" 말풍선이 FAB 왼쪽 옆에 나와서 하단 네비게이션 바와 겹침
- **수정 파일**: `components/chatbot/ChatFloatingButton.tsx`
- **수정 내용**:
  - 말풍선 위치: `right:76, bottom:80` → `right:8, bottom:138` (FAB 위쪽)
  - 말풍선 꼬리: 오른쪽 → 아래쪽 (FAB을 가리킴)
  - 슬라이드 애니메이션: `translateX` → `translateY`

## 6. 지도 — "주변시설보기" 버튼 숨김 보강
- **문제**: 지도 탭하면 네비게이션은 사라지는데 "주변시설보기" 버튼은 안 사라짐
- **수정 파일**: `components/map/NaverMap.tsx`
- **수정 내용**: `uiHidden` 시 `opacity: 0` + `pointerEvents: 'none'` 추가

## 7. Material Symbols 아이콘 FOUT 방지
- **문제**: 아이콘 폰트 로드 전 텍스트("call", "star", "chat_bubble")가 잠깐 보임
- **수정 파일**: `app/layout.tsx`
- **수정 내용**:
  - 기존: `document.fonts.ready` → 폰트 다운로드 전에도 resolve될 수 있음
  - 개선: `document.fonts.check('24px "Material Symbols Outlined"')` 폴링 → 실제 렌더링 가능 시점 정확 감지
  - 안전장치: 3초 후 강제 표시 (무한 대기 방지)
