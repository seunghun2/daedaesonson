각 시설 상세페이지의 "이야기" 섹션을 채운다.

## 📋 실행 단계 (총 5단계)

### Phase 1: 시설 → 네이버 Place ID 매칭 🔗

**목적**: 우리 DB의 시설 ID와 네이버 지도의 place ID를 매칭

**스크립트**: `scripts/naver-place-match.js`

**로직**:
```
1. DB에서 시설 목록 가져오기 (id, name, address)
2. 시설명 전처리 (정규화)
   - "재낙원추모공원" → "낙원추모공원" (접두사 '재' 제거)
   - "재단법인 아너스홈 구 대성공원묘원" → "대성공원묘원"
   - "(재)호정공원(봉안)" → "호정공원"
3. 네이버 지도 검색: `https://m.map.naver.com/search2/search.naver?query={시설명}+{시/군}`
4. 검색 결과에서 첫 번째 장소의 place ID 추출
5. 주소 교차검증: 네이버 결과 주소 vs 우리 DB 주소 (시/군 일치 확인)
6. 매칭 결과 저장: naver_place_mapping.csv
```

**출력 CSV 형식**:
```csv
facilityId,facilityName,address,naverPlaceId,naverName,naverAddress,matchStatus,reviewCount
park-0001,재낙원추모공원,경기도 양주시...,1234567890,낙원추모공원,경기도 양주시...,MATCHED,58
park-0002,재실로암공원묘원,경기도 포천시...,,,NOT_FOUND,0
```

**matchStatus 값**:
- `MATCHED`: 시설명+주소 모두 일치
- `NAME_ONLY`: 시설명만 일치 (수동 확인 필요)
- `NOT_FOUND`: 검색 결과 없음

**속도 제한**:
- 요청 간 3~5초 랜덤 딜레이
- 시간당 최대 100건
- 1,495건 → 약 4~5시간 (2~3일에 나눠서 가능)

**체크포인트**: 
- 중간 저장 기능 (500건마다 CSV 저장)
- `--start=N` 옵션으로 이어서 실행 가능

---

### Phase 2: 리뷰 존재 여부 필터링 📋

**목적**: 매칭된 시설 중 리뷰가 있는 곳만 추리기

**로직**:
```
1. naver_place_mapping.csv에서 MATCHED인 것만 필터
2. 각 place의 리뷰 페이지 접근: https://m.place.naver.com/place/{placeId}/review/visitor
3. "방문자 리뷰 N" 에서 리뷰 수 추출
4. reviewCount > 0인 시설만 리뷰 수집 대상으로 마킹
```

**출력**: `naver_place_mapping.csv`의 reviewCount 컬럼 업데이트

---

### Phase 3: 리뷰 텍스트 수집 📝

**목적**: 리뷰가 있는 시설에서 실제 리뷰 내용 크롤링

**스크립트**: `scripts/naver-review-crawl.js`

**로직**:
```
1. reviewCount > 0인 시설 목록 로드
2. 각 시설의 리뷰 페이지 접근
3. ⭐ 리뷰 전체 수집 (제한 없음, 모든 리뷰 크롤링):
   - 페이지 스크롤 → "더보기" 반복 클릭하여 전체 리뷰 로드
   - 닉네임 → 마스킹 (김철수 → 김**)
   - 리뷰 본문 텍스트 ("더보기" 클릭으로 전문 확보)
   - 작성 날짜 (상대 → 절대 변환: "3주 전" → 2026-03-18)
   - 별점 (좋아요→5, 보통→3, 별로→1)
   - 사진 URL (있으면)
4. JSON + 시설별 MD 파일로 저장
```

**수집 데이터 구조** (JSON):
```json
{
  "facilityId": "park-0565",
  "facilityName": "분당스카이캐슬추모공원",
  "naverPlaceId": "1234567890",
  "totalReviews": 58,
  "reviews": [
    {
      "author": "김**",
      "content": "아버지를 모셨는데 주변 환경이 좋고 관리도 잘 해주셔서 만족합니다.",
      "rating": 5,
      "date": "2025-11-20",
      "photos": [],
      "source": "naver",
      "sourceUrl": "https://m.place.naver.com/place/1234567890/review/visitor"
    }
  ]
}
```

**시설별 MD 파일 예시** (`scraped-reviews/park-0565_분당스카이캐슬추모공원.md`):
```markdown
# 분당스카이캐슬추모공원 - 네이버 리뷰

- 시설 ID: park-0565
- 네이버 Place ID: 1234567890
- 총 리뷰 수: 58건
- 수집일: 2026-04-08

---

## 리뷰 1 | 김** | ⭐ 좋아요 | 2025-11-20
아버지를 모셨는데 주변 환경이 좋고 관리도 잘 해주셔서 만족합니다.

## 리뷰 2 | 박** | ⭐ 좋아요 | 2025-09-03
시설이 깨끗하고 직원분들이 친절합니다.

...
```

**속도 제한**:
- 리뷰 페이지 접근 시 5~8초 랜덤 딜레이
- "더보기" 클릭 시 2~3초 대기
- 페이지 스크롤 시 1~2초 대기
- 시간당 약 30~40개 시설 처리 가능 (전체 리뷰 수집이라 더 느림)

**출력 파일**:
- `scraped-reviews/naver_reviews.json` (전체 통합)
- `scraped-reviews/md/{시설ID}_{시설명}.md` (시설별 MD)

### Phase 4: 검수 ✅

**목적**: 수집된 리뷰의 품질 확인 & 부적절한 리뷰 제거

**검수 기준**:
- ❌ 삭제 대상:
  - 욕설/비방 ("최악이다", "사기꾼" 등)
  - 광고성 리뷰
  - 시설과 무관한 리뷰
  - 개인정보 노출 (전화번호, 이름 등)
  - 1글자 리뷰 ("ㅋ", "." 등)
- ✅ 유지 대상:
  - 시설 환경/서비스에 대한 솔직한 후기
  - 시설 이용 과정 설명
  - 장단점 비교

**검수 방식**: JSON → CSV 변환 → 사람이 확인 → 삭제할 행 제거

---

### Phase 5: DB 삽입 💾

**목적**: 검수 완료된 리뷰를 Review 테이블에 일괄 삽입

**스크립트**: `scripts/naver-review-insert.js`

**로직**:
```
1. 검수된 JSON/CSV 로드
2. Review 테이블에 삽입:
   - facilityId: 우리 시설 ID
   - author: 마스킹된 닉네임
   - content: 리뷰 본문
   - rating: 변환된 별점
   - source: 'naver'
   - sourceUrl: 네이버 리뷰 페이지 URL
   - sourceDate: 원본 작성일
   - password: null (크롤링 리뷰는 삭제 불가)
   - likes: 0
3. Facility 테이블 업데이트:
   - reviewCount: 기존 + 새로 추가된 리뷰 수
   - rating: 전체 리뷰 평균 별점 재계산
```
