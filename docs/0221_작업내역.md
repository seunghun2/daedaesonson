**가격 표시 Flash 제거** 및 **가격 데이터 정합성 확보**

## 📌 작업 항목

### 1. 가격 Flash 효과 제거
- **문제**: 마커 클릭 시 가격이 "216만원~" → "300만원~"로 변경되는 깜빡임 현상
- **원인**: SSR 기본 데이터(stale minPrice)로 먼저 렌더링 → API 데이터(priceTable 기반 정확 가격)로 재렌더링
- **해결**:
  - 기본 정보(이름, 이미지, 주소)는 **즉시 표시**
  - 가격 섹션은 `priceTable`이 없으면 `return null` → API 데이터 도착 후 **한 번에 표시**
  - Flash 없이 자연스럽게 가격 섹션이 나타남

### 2. Stale minPrice 폴백 차단
- **문제**: `priceTable`이 있는 시설인데도 stale `minPrice`(DB의 오래된 값)로 폴백되어 잘못된 가격 표시
- **해결**: `priceTable`이 존재하면 `priceRange.min` 폴백 **절대 차단**
- **적용 파일** (4곳 통일):
  - `app/page.tsx` — SSR 초기 데이터
  - `components/map/NaverMap.tsx` — 마커 가격
  - `components/list/FacilityCard.tsx` — 리스트 카드 가격
  - `components/detail/FacilityDetail.tsx` — 상세 페이지 가격

### 3. 좌표 정밀도 유지
- **문제**: `facilities.json`의 정밀 좌표(소수점 7자리)가 DB 동기화 시 반올림된 좌표(소수점 2자리)로 덮어씀
  - 마커 클릭 시 지도가 엉뚱한 위치로 이동
- **해결**:
  - `scripts/sync_facilities_json.js`: DB에서 좌표 덮어쓰기 방지, 기존 정밀 좌표 유지
  - `HomeClient.tsx`: API 상세 데이터 수신 시 SSR 정밀 좌표 유지 (`data.coordinates = facility.coordinates`)

### 4. 지도 이동 로직 개선
- **변경 전**: `useEffect`에서 `selectedFacility` 변경 시 자동 panTo (API의 반올림 좌표 사용)
- **변경 후**: 마커 클릭 핸들러에서 **SSR 정밀 좌표로 직접 panTo**

### 5. 가격표 UI 개선
- **패딩**: 아코디언 항목 좌우 패딩 `16px` → `24px` (헤더와 항목 구분)
- **`?` 설명 아이콘**:
  - `봉안묘` 카테고리 설명 추가 (기존 목록에 빠져있었음)
  - priceTable(V1) 뷰에도 `?` 아이콘 + 설명 추가
  - 설명 박스를 `Accordion.Panel` 내부로 이동 (배경 겹침 해결)
- **`?` ↔ 아코디언 연동**:
  - 아코디언 닫힌 상태에서 `?` 클릭 → 아코디언 자동 열림 + 설명 표시
  - Controlled 아코디언으로 전환 (`value` + `onChange`)
  - 초기값: 카테고리 1개인 서비스타입은 자동 열림

### 6. ★ 없는 카테고리 최저가 자동 표시
- **문제**: 봉안당에 ★ 대표항목이 없으면 대표 가격 미표시
- **해결**: ★ 없는 카테고리도 최저가를 자동으로 `menuGroups`에 추가
- **결과**: 봉안당 + 매장묘지 등 복수 카테고리 가격 동시 표시

### 7. representativePrice 우선 사용
- DB `representativePrice` 컬럼을 **0순위**로 확인
- 마커, 카드, 상세 페이지 모두 통일된 가격 표시
- `scripts/sync_rep_price_to_db.js` 생성: priceTable → DB representativePrice 동기화

## 🔧 가격 표시 우선순위 (최종)

```
┌─ 0순위: DB representativePrice (어드민 precomputed) ──────────┐
│  → 있으면 바로 사용                                            │
├─ 1순위: priceTable ★ isRepresentative 항목 ──────────────────┤
│  → 카테고리별 대표항목 직접 계산                                 │
├─ 2순위: representativePricing (CSV 기반) ─────────────────────┤
│  → 레거시 폴백                                                │
├─ 3순위: priceRange.min (DB minPrice) ────────────────────────┤
│  → ⚠️ priceTable이 있으면 절대 사용 안 함!                      │
│  → priceTable이 아예 없는 레거시 시설만 사용                      │
└──────────────────────────────────────────────────────────────┘
```
