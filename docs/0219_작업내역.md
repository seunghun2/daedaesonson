### 5. ⭐ ScrollableTabsList 공통 컴포넌트 생성 (핵심!)
- **파일**: `components/ScrollableTabsList.tsx` (신규 생성)
- **Mantine의 `Tabs.List`를 래핑한 스크롤 가능 탭 리스트 컴포넌트**

#### 기능 상세:

##### 5-1. PC 드래그 스크롤
- 마우스로 탭 영역을 잡고 좌우로 드래그하면 스크롤
- `cursor: grab` → `cursor: grabbing` 상태 전환
- 드래그 후 클릭 방지 (탭 오작동 방지): `hasDragged` 플래그로 관리
- capture phase 이벤트 리스너로 드래그 시 `e.stopPropagation()` 처리

##### 5-2. 모바일 터치 스와이프
- `WebkitOverflowScrolling: 'touch'`로 네이티브 터치 스크롤 지원
- `scrollbarWidth: 'none'`으로 스크롤바 숨김

##### 5-3. `>` 화살표 인디케이터
- 오른쪽에 더 탭이 있을 때 `>` 화살표 + 그라디언트 페이드 표시
- 끝까지 스크롤하면 자동으로 사라짐
- **클릭 가능**: 화살표 누르면 120px 오른쪽으로 스크롤
- **배경색**: `var(--mantine-color-body)` — 실제 페이지 배경색과 동일하게 매칭
- `ResizeObserver`로 화면 크기 변경 시 자동 업데이트

##### 5-4. 탭 클릭 시 중앙 정렬
- 탭을 클릭하면 해당 탭이 스크롤 영역 중앙으로 이동
- 좌우에 다른 탭이 보이므로 "더 있다"는 것을 직관적으로 알 수 있음
- `setTimeout(100ms)`으로 Mantine 탭 전환 후 스크롤 적용

##### 5-5. 하단 라인(border) 전체 너비 확장
- **문제**: `overflow-x: auto` + `flexWrap: nowrap` 사용 시, Tabs.List의 `border-bottom`이 스크롤 콘텐츠 영역까지 확장되지 않는 문제
- **해결**: 
  - wrapper `div`에 `borderBottom` 적용 (항상 전체 너비)
  - Tabs.List의 `borderBottom: 'none'` + `marginBottom: -2px`로 active 인디케이터와 정확히 정렬

## 🔧 기술 구현 세부사항

### ScrollableTabsList 이벤트 흐름
```
mousedown → isDown=true, startX 기록
  ↓
mousemove → |dx| > 4px이면 hasDragged=true, el.scrollLeft 업데이트
  ↓
mouseup → isDown=false, checkScroll() 호출
  ↓
click (capture) → hasDragged면 preventDefault+stopPropagation
                → 아니면 탭 중앙 정렬 실행
```

### 스크롤 상태 감지
```
checkScroll() 함수:
  canScroll = scrollWidth > clientWidth + 2  (오차 보정)
  atEnd = scrollLeft + clientWidth >= scrollWidth - 4
  showArrow = canScroll && !atEnd
```

### CSS 구조
```
<div style="position:relative; border-bottom:2px solid gray; margin-bottom:var(--mb)">
  <Tabs.List style="border-bottom:none; margin-bottom:-2px; overflow-x:auto; flex-wrap:nowrap">
    <Tabs.Tab style="flex-shrink:0">로얄관</Tabs.Tab>
    <Tabs.Tab style="flex-shrink:0">아트리움관</Tabs.Tab>
    ...
  </Tabs.List>
  <div class="arrow" style="position:absolute; right:0; background:gradient">
    <ChevronRight />
  </div>
</div>
```

## 🖼️ UI 변경 비교

### 변경 전
- 탭이 여러 줄로 wrap됨
- 관리비 탭이 중간에 섞여있음
- PC에서 스크롤 불가 (스크롤바 숨김 시)
- 더 많은 탭이 있는지 알 수 없음

### 변경 후
- 탭이 한 줄로 정렬, 가로 스크롤
- 관리비는 항상 마지막
- PC: 마우스 드래그로 스크롤 가능
- 모바일: 터치 스와이프로 스크롤
- `>` 화살표로 더 있음을 표시
- 화살표 클릭 시 스크롤
- 탭 클릭 시 중앙 정렬로 좌우 탭 확인 가능
