### 1. FacilityDetail (742-4683줄)
**역할**: 시설 상세 정보 전체를 렌더링하는 메인 컴포넌트

#### Props
```typescript
interface FacilityDetailProps {
    facility: Facility;           // 시설 데이터
    onClose: () => void;          // 닫기 콜백
    allFacilities?: Facility[];   // 주변 시설 목록
    onSelectFacility?: (id: string) => void;  // 시설 선택 콜백
    onMapView?: (lat: number, lng: number) => void;  // 지도 이동
    initialConsultOpen?: boolean;  // 상담 모달 초기 오픈
    isDesktop?: boolean;          // PC 레이아웃 여부
}
```

#### 주요 상태 (State)
```typescript
// 시설 데이터
const [facility, setFacility] = useState(initialFacility);
const [priceInfo, setPriceInfo] = useState(null);       // API에서 가져온 가격 정보
const [reviews, setReviews] = useState<Review[]>([]);   // 후기 목록

// UI 상태
const [activeTab, setActiveTab] = useState('info');     // 하단 탭 (정보/후기/문의)
const [viewerOpen, setViewerOpen] = useState(false);    // 이미지 뷰어
const [consultModalOpened, setConsultModalOpened] = useState(false); // 상담 모달

// 찜 기능
const [isWished, setIsWished] = useState(false);
const [wishCount, setWishCount] = useState(0);

// 후기/문의 폼
const [reviewContent, setReviewContent] = useState('');
const [reviewRating, setReviewRating] = useState(5);
const [inquiryContent, setInquiryContent] = useState('');
```

#### 데이터 흐름
```
시설 ID → API 호출 (/api/facilities/[id])
         → priceInfo 상태 업데이트
         → PriceInfoSection에 전달
         → 가격 탭/테이블 렌더링
```

#### 가격 Flash 방지
```
마커 클릭
  → 기본 정보(이름, 이미지, 주소) 즉시 표시
  → API /api/facilities/[id] 호출
  → priceInfo 도착 → 가격 섹션 한 번에 렌더링
  → Flash 없음 ✅
```

#### 가격 표시 우선순위 (통일)
```
0순위: DB representativePrice (precomputed)
1순위: priceTable ★ isRepresentative 항목
2순위: representativePricing (CSV 기반, 레거시)
3순위: priceRange.min (⚠️ priceTable 있으면 사용 안 함)
```

### 2. PriceInfoSection (72-659줄)
**역할**: 가격 정보를 V2(표준화) 또는 V1(레거시) 형식으로 렌더링

#### Props
```typescript
{ priceInfo: any, hasPrice: boolean, facilityName?: string, websiteUrl?: string }
```
- `facilityName`: 공식 홈페이지 링크에 시설명 표시용
- `websiteUrl`: 있으면 가격 섹션 하단에 "공식 홈페이지 바로가기" 링크 노출

#### 하단 요소 순서
```
가격 탭/테이블
  ↓
면책 안내 텍스트 (배경 없음, Text size="xs" c="dimmed")
  ↓
─────────────────────────── (구분선, websiteUrl 있을 때만)
○○○ 공식 홈페이지  바로가기 ↗  (ExternalLink SVG 아이콘)
  - "공식 홈페이지" → dark.7 (검은색)
  - "바로가기" + 아이콘 → brand.6 (본컬러)
```
#### 가격 데이터 구조

##### V2 표준화 가격 (standardizedPrices)
```typescript
// API 응답 형태
{
  standardizedPrices: [
    {
      serviceType: "BONGSAN" | "NATURAL" | "BURIAL",
      subType: "INDIVIDUAL" | "COUPLE" | "FAMILY" | ...,
      groupType: "로얄관" | "아트리움관" | "관리비" | ...,
      rows: [
        { name: "1단", price: 5000000, isRepresentative: true },
        { name: "2단", price: 5000000 },
        ...
      ]
    }
  ]
}
```

##### V1 레거시 가격 (optionRows)
```typescript
{
  optionRows: [
    {
      category: "봉안(납골)",    // 카테고리
      groupType: "로얄관",      // 그룹 타입
      name: "1단",              // 옵션명
      price: "5,000,000원"      // 가격 (문자열)
    }
  ]
}
```

#### 렌더링 로직
```
priceInfo 수신
  ├── standardizedPrices 있으면?
  │   ├── 서비스타입별 그룹화 (BONGSAN, BURIAL, NATURAL)
  │   ├── 메인 탭: 봉안당 → 매장묘 → 수목장 순서
  │   └── 서브타입별 아코디언
  │       ├── groupType별 탭 (로얄관, 아트리움관, ..., 관리비)
  │       └── 각 그룹의 가격 테이블
  │
  └── optionRows만 있으면? (레거시)
      ├── 카테고리별 아코디언 (봉안(납골), 자연장, 매장)
      └── groupType별 탭
          └── 가격 테이블
```

#### 서브타입 `?` 설명 아이콘
```typescript
const getSubTypeDescription = (subType: string) => {
    const map = {
        '매장묘': '시신을 땅에 묻는 전통 장법입니다...',
        '평장묘': '봉분을 만들지 않고...',
        '봉안묘': '화장 후 유골을 묘지 형태로 안치...',
        '봉안담': '화장 후 유골함을 담 형태...',
        '봉안당': '화장 후 유골을 봉안당(납골당)에 안치...',
        '수목장': '화장 후 유골을 나무 밑에...',
        '잔디장': '화장 후 유골을 잔디밭 아래에...',
        '자연장': '화장 후 유골을 자연에...',
    };
};
```
- `?` 클릭 → 설명 토글 + 아코디언 닫혀있으면 자동 열림
- Controlled 아코디언 (`value` + `onChange` + `openAccItems` state)
- 초기값: 카테고리 1개인 서비스타입은 자동 열림
- V1(priceTable)과 V2(standardizedPrices) 모두에 `?` 아이콘 적용

#### 탭 순서 로직
```typescript
// 메인 탭 (서비스 타입)
const serviceOrder = { 'BONGSAN': 0, 'BURIAL': 1, 'NATURAL': 2 };
serviceTypes.sort((a, b) => (serviceOrder[a] ?? 99) - (serviceOrder[b] ?? 99));

// 서브탭 (그룹 타입) - 관리비 항상 마지막
usageGroupNames.sort((a, b) => {
    const aIsMgmt = /관리비/.test(a) ? 1 : 0;
    const bIsMgmt = /관리비/.test(b) ? 1 : 0;
    return aIsMgmt - bIsMgmt;
});

// 서비스 라벨 변환
getServiceLabel(type: string) {
    BONGSAN → '봉안당'
    NATURAL → '수목장'
    BURIAL  → '매장묘'
}
```

## 📊 가격 표시 형식

### 가격 포맷
- `formatKoreanCurrency(5000000)` → `"500만원"`
- `formatKoreanCurrency(12500000)` → `"1,250만원"`
- `formatKoreanCurrency(350000)` → `"35만원"`

### 대표 가격 (isRepresentative)
- 시설 목록 및 지도 마커에 표시되는 최저 대표 가격
- `⭐` 아이콘으로 표시
- 대표 가격이 없으면 전체 항목 중 최저가 사용
- **priceTable이 있으면 priceRange.min(DB) 폴백 절대 차단** → "문의" 표시
