# 📝 블로그 발행 워크플로우

> 사용자가 대본/주제를 주면 → Antigravity가 글 작성 + 이미지 생성 + 발행하는 프로세스

---

## 🔄 발행 프로세스

```
사용자: 대본(주제/원고) 전달
    ↓
Antigravity: 1. HTML 콘텐츠 작성
             2. 삽입 이미지 생성 (generate_image)
             3. 썸네일 생성
             4. public/blog/에 이미지 배치
             5. Supabase blog_posts에 INSERT
             6. git commit & push (Vercel 자동 배포)
    ↓
완료: /guide/슬러그 에서 공개 + SEO 자동 적용
```

---

## 📋 사용자가 줘야 할 것

### 필수
- **주제 / 대본** — 어떤 내용의 글을 쓸 것인지

### 선택 (안 주면 Antigravity가 판단)
- 카테고리 (`봉안당 가이드` / `수목장 가이드` / `비용 안내` / `장례 절차` / `시설 리뷰` / `가이드` / `공지사항`)
- 원하는 톤앤매너 (예: 전문적, 친근한, 후기체 등)
- 참고 자료/링크
- 이미지 스타일 선호

### 요청 예시
```
블로그 글 발행해줘.

주제: 수목장이 뭔지, 왜 인기 많은지, 어떻게 선택하는지
카테고리: 수목장 가이드
이미지 4장정도 넣어줘
```

## ⚙️ Antigravity 처리 상세

### 1단계: 콘텐츠 작성
- 대본 기반으로 SEO 최적화된 HTML 본문 작성
- H2/H3 구조, 표, 리스트, 인용구 활용
- 내부 링크 (`/` 지도, `/list` 시설목록) 자연스럽게 삽입
- 분량: 1,000~2,000자 (SEO 최적)

### 2단계: 이미지 생성 & 배치
- `generate_image` 도구로 삽입 이미지 + 썸네일 생성
- `public/blog/` 폴더에 저장
- 파일명: `blogN_imgN.png`, `thumbnail-주제.png`
- 본문 HTML에 `<img src="/blog/..." alt="..." />` 삽입

### 3단계: Supabase에 글 등록
- `blog_posts` 테이블에 INSERT
- 필드: title, slug, category, excerpt, content, thumbnail_url, author, tags, is_published=true

### 4단계: 커밋 & 배포
```bash
git add public/blog/ app/  # 이미지 + 코드 변경사항
git commit -m "feat: 블로그 N번째 글 발행 - [제목 요약]"
git push origin main       # Vercel 자동 배포
```

### 5단계: SEO 자동 적용 (별도 작업 없음)
- 메타태그/OG태그 자동 생성
- sitemap.xml에 자동 추가
- Google/네이버 자동 인덱싱
