## 📋 사용자가 줘야 할 것

### 필수 (이것만 있으면 발행 가능)
**대본 또는 주제** — 아래 중 하나의 형태로 전달

#### 형태 1: 주제만 (가장 간단)
```
블로그 글 발행해줘.
주제: 수목장이 뭔지, 왜 인기 많은지
```
→ Antigravity가 주제를 기반으로 전체 콘텐츠를 기획·작성

#### 형태 2: 핵심 포인트 나열
```
블로그 글 발행해줘.
주제: 봉안당 관리비 안내

포인트:
- 관리비가 뭔지
- 공설 vs 사설 관리비 차이
- 연간 관리비 범위: 공설 0~3만원, 사설 3~10만원
- 관리비 미납하면 어떻게 되는지
- 관리비 포함된 곳 vs 별도인 곳
```
→ Antigravity가 포인트를 살려서 풍부한 HTML 콘텐츠로 확장

#### 형태 3: 전체 원고 (가장 정확)
```
블로그 글 발행해줘.

제목: 봉안당 관리비, 얼마나 내야 할까?

[전체 원고 텍스트...]
```
→ Antigravity가 원고를 그대로 HTML 포맷으로 변환 + 이미지 삽입

### 선택 (안 줘도 Antigravity가 알아서 판단)

| 항목 | 설명 | 안 주면? |
|------|------|---------|
| 카테고리 | 7개 중 택1 (아래 참조) | 내용 보고 자동 선택 |
| 이미지 수 | 본문 삽입 이미지 몇 장? | 4~6장 기본 생성 |
| 톤앤매너 | 전문적 / 친근 / 후기체 등 | 친근 + 전문적 (기본) |
| 참고 자료 | URL, 이미지, 문서 등 | 대대손손 데이터 활용 |
| 제목 | 원하는 제목 | SEO 최적화 제목 자동 생성 |

## ⚙️ Antigravity 처리 상세 (단계별)

### ① 콘텐츠 작성

**입력**: 사용자의 대본/주제
**출력**: SEO 최적화된 HTML 본문

작성 규칙:
- **분량**: 1,500~2,500자 (SEO 최적 범위)
- **구조**: H2 → H3 → P 계층적 구조
- **SEO**: 제목·본문에 검색 키워드 자연스럽게 포함
- **표/리스트**: 가격 비교, 체크리스트 등은 표·리스트 활용
- **인용구**: 핵심 내용은 `<blockquote>`로 강조 (이모지 사용 금지)
- **내부링크**: 대대손손 지도(`/`), 시설목록(`/list`) 자연스럽게 삽입
- **CTA**: 본문에 CTA 버튼 넣지 않음 (페이지 자체 CTA 활용)
- **톤앤매너**: `블로그발행/` 폴더의 톤앤매너 정의서 v1.0 준수

톤앤매너 핵심 (정의서 v1.0 기준):
- 감정 0, 실용성 100 — 데이터 저널리스트 톤
- 1인칭 감성 서사 금지 / 뻔한 도입부 금지
- 모든 수치에 출처 명시 (통계청, 보건복지부 등)
- 소제목은 질문형 또는 주장형
- 문단 3줄 이내
- 경쟁사 언급 금지
- 이모지 사용 금지

HTML 태그 사용:
```html
<h2>큰 제목</h2>
<h3>소제목</h3>
<p>본문 텍스트. <strong>굵은 글씨</strong> 가능.</p>
<img src="/blog/blogN_imgN.png" alt="SEO용 설명" />
<ul><li>항목</li></ul>
<ol><li>순서 항목</li></ol>
<table>...(가격 비교 등)</table>
<blockquote>핵심 내용 (이모지 없이)</blockquote>
<hr />
```

### ② 이미지 생성

**도구**: `generate_image` (AI 이미지 생성)
**생성 목록**:
- 썸네일 1장: `thumbnail-주제요약.png` (16:9, 목록·OG 이미지용)
- 본문 이미지 4~6장: `blogN_img1.png` ~ `blogN_img6.png`

이미지 스타일:
- 장례/추모 관련: 차분하고 절제된 톤
- 가격/비교: 인포그래픽 스타일
- 시설 리뷰: 풍경/건물 스타일
- 가이드: 친근한 일러스트 스타일

### ③ 이미지 배치

```
public/blog/
├── thumbnail-funeral-guide.png        ← 글1 썸네일
├── blog1_img1.png ~ blog1_img4.png    ← 글1 본문
├── thumbnail-price-difference.png     ← 글2 썸네일
├── blog2_img1.png ~ blog2_img4.png    ← 글2 본문
├── thumbnail-gyeonggi-top5.png        ← 글3 썸네일
├── blog3_img1.png ~ blog3_img6.png    ← 글3 본문
│
│  ↓↓↓ 다음 글 부터 ↓↓↓
│
├── thumbnail-다음주제.png              ← 글4 썸네일
├── blog4_img1.png ~ blog4_imgN.png    ← 글4 본문
└── ...
```

넘버링 규칙: `blog{글번호}_img{이미지번호}.png`
- 글4의 첫 번째 이미지 → `blog4_img1.png`
- 글4의 세 번째 이미지 → `blog4_img3.png`

### ④ Supabase 등록

`blog_posts` 테이블에 INSERT:

| 컬럼 | 타입 | 값 결정 방식 |
|------|------|-------------|
| `id` | uuid | 자동 생성 |
| `title` | text | 사용자 지정 또는 자동 생성 |
| `slug` | text | 제목 기반 영문 변환 (예: `natural-burial-beginner-guide`) |
| `category` | text | 사용자 지정 또는 자동 판단 |
| `excerpt` | text | 본문 요약 2~3줄 자동 생성 |
| `content` | text | 작성된 HTML 전체 |
| `thumbnail_url` | text | `/blog/thumbnail-xxx.png` |
| `author` | text | `대대손손` (기본값) |
| `tags` | text[] | SEO 키워드 기반 5~8개 |
| `is_published` | boolean | `true` (즉시 공개) |
| `view_count` | integer | 초기값 설정 (50~200) |
| `created_at` | timestamp | 현재 시각 |
| `updated_at` | timestamp | 현재 시각 |

### ⑤ 커밋 & 배포

```bash
# 이미지 파일 추가
git add public/blog/blogN_*.png public/blog/thumbnail-*.png

# 커밋
git commit -m "feat: 블로그 N번째 글 발행 - [제목 요약]"

# 푸시 → Vercel 자동 배포 (약 1~2분 소요)
git push origin main
```

### ⑥ SEO 자동 적용 (별도 작업 없음)

| 항목 | 어떻게 적용되는지 |
|------|----------------|
| 메타 title | `{글 제목} \| 대대손손 가이드` — `generateMetadata` 자동 생성 |
| 메타 description | `excerpt` (요약) 사용 — `generateMetadata` 자동 생성 |
| OG 이미지 | `thumbnail_url` 사용 — 카카오/페이스북 공유 시 노출 |
| OG 타입 | `article` — 블로그 글 최적화 |
| Twitter 카드 | `summary_large_image` — 트위터 공유 시 큰 이미지 |
| sitemap.xml | Supabase에서 발행된 글 목록 조회 → 동적 URL 추가 |
| robots.txt | `/guide/*` 크롤링 허용 (설정 완료) |
| Google | sitemap 제출 완료 (서치콘솔) → 자동 크롤링 |
| 네이버 | sitemap 제출 완료 (서치어드바이저) → 자동 크롤링 |

## 🛠️ 기술 인프라 요약

### DB 테이블: `blog_posts` (Supabase)
```sql
id              uuid PRIMARY KEY DEFAULT gen_random_uuid()
title           text NOT NULL
slug            text NOT NULL UNIQUE
category        text DEFAULT '가이드'
excerpt         text
content         text NOT NULL          -- HTML 본문
thumbnail_url   text
author          text DEFAULT '대대손손'
tags            text[]                 -- 배열
is_published    boolean DEFAULT false
view_count      integer DEFAULT 0
created_at      timestamptz DEFAULT now()
updated_at      timestamptz DEFAULT now()
```

### 프론트엔드 파일
```
app/guide/page.tsx           ← 블로그 목록 (클라이언트 컴포넌트)
app/guide/layout.tsx         ← 목록 SEO 메타데이터
app/guide/loading.tsx        ← 목록 로딩 UI
app/guide/[slug]/page.tsx    ← 상세 SSR + generateMetadata
app/guide/[slug]/BlogDetailClient.tsx  ← 상세 클라이언트 렌더링
app/guide/[slug]/loading.tsx ← 상세 로딩 UI
```

### API
```
GET  /api/blog              ← 공개 목록 (발행된 글만)
GET  /api/blog/[slug]       ← 공개 상세 + 조회수 증가
GET  /api/admin/blog        ← 어드민 목록 (미발행 포함)
POST /api/admin/blog        ← 글 생성
PUT  /api/admin/blog/[id]   ← 글 수정
DEL  /api/admin/blog/[id]   ← 글 삭제
```

### SEO 파일
```
app/sitemap.ts    ← 블로그 URL 동적 포함
app/robots.ts     ← /guide 크롤링 허용
```
