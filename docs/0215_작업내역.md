## 4️⃣ 태블릿 이미지 저장 버그 수정

### 문제
- 배포 서버에서 태블릿으로 이미지를 넣고 저장하면 이미지가 저장되지 않음
- PC에서는 정상 동작

### 원인 분석
- `FileButton`의 `accept="image/png,image/jpeg"`가 태블릿의 **HEIC/HEIF** 포맷을 차단
- iPad/태블릿 카메라 촬영 이미지는 기본적으로 HEIC 포맷으로 저장됨
- HEIC 파일이 선택은 되지만 압축 과정(`canvas.toBlob('image/jpeg')`)에서 변환 실패 가능

### 해결
- `accept="image/png,image/jpeg"` → `accept="image/*"` 변경
- 이미지 추가 버튼, 스크린샷 자르기 버튼 **모두** 변경

### 변경 파일
- `app/admin/upload/FacilityEditModal.tsx`:
  - 905줄: 이미지 추가 FileButton accept 변경
  - 908줄: 스크린샷 자르기 FileButton accept 변경
