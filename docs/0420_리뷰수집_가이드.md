#### 옵션 설명

| 옵션 | 설명 | 예시 |
|------|------|------|
| `--min=N` | 리뷰 N건 이상 시설만 대상 | `--min=50` (30개 대상) |
| `--limit=N` | 최대 N개 시설만 처리 | `--limit=10` (테스트용) |
| `--reset` | 기존 naver_reviews.json 초기화 후 시작 | |

### Step 5: 검수 (Phase 4)

수집 완료 후 검수:

```bash
# CSV로 변환해서 검수
node -e "
const d = require('./scraped-reviews/naver_reviews.json');
let csv = 'facilityId,facilityName,author,content,rating,date\n';
d.forEach(f => f.reviews.forEach(r => {
  csv += [f.facilityId, f.facilityName, r.author, 
    '\"'+r.content.replace(/\"/g,'\"\"')+'\"', r.rating, r.date].join(',') + '\n';
}));
require('fs').writeFileSync('scraped-reviews/reviews_for_check.csv', csv);
console.log('CSV 생성 완료');
"
```

삭제 대상:
- ❌ 욕설/비방
- ❌ 광고성 리뷰
- ❌ 시설과 무관한 내용
- ❌ 1글자 리뷰
