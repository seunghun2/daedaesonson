## 📊 시장 분석

### 시장 규모
- 국내 장례 서비스 시장: 연간 **약 4조원**
- 연간 사망자 수: 약 35만명 (고령화로 증가 추세)
- 장례시설(봉안당, 수목장, 공원묘지): 전국 **약 1,500개**

### 문제점 (Pain Point)
1. **정보 파편화**: 시설별로 흩어진 정보, 비교 어려움
2. **가격 불투명**: 전화 문의 없이 가격 확인 불가
3. **접근성 부족**: 고령층 사용자, 디지털 정보 부재
4. **신뢰도 문제**: 검증되지 않은 정보, 후기 부재

### 경쟁사 현황
| 서비스 | 특징 | 한계 |
|--------|------|------|
| 개별 시설 웹사이트 | 해당 시설 정보만 | 비교 불가 |
| 네이버/카카오 지도 | 위치 정보 | 상세 가격 없음 |
| 장례정보원 | 공공 데이터 | UX 떨어짐, 가격 없음 |

### 차별화 포인트
1. **전국 1,500개 시설** 통합 데이터베이스
2. **가격 정보 투명 공개** (1,825개 가격 항목)
3. **지도 기반 직관적 검색** (호갱노노 스타일)
4. **자동화된 데이터 수집** (크롤링 파이프라인)

## 🎯 작성 톤앤매너 (매우 중요!)

### ⚠️ AI 탐지 방지 - 반드시 사람처럼 자연스럽게!

**절대 AI스러운 문체 금지!** 정부 평가에서 AI 작성 여부를 검토하므로:

1. **완벽한 문장 구조 피하기**
   - 때로는 짧은 문장, 때로는 긴 문장 섞기
   - 모든 문단이 동일한 패턴 ❌

2. **과도한 나열/병렬구조 피하기**
   - "첫째... 둘째... 셋째..." 반복 ❌
   - 자연스러운 흐름으로 연결

3. **개인적인 뉘앙스 포함**
   - "직접 개발하며 느낀 점은..."
   - "시장을 조사하면서 발견한 것은..."
   - 창업자의 실제 경험담처럼

4. **약간의 구어체 허용**
   - 딱딱한 보고서체만 ❌
   - 진정성 있는 표현 사용

5. **일부러 완벽하지 않게**
   - 모든 문장이 깔끔하게 정리되면 오히려 의심
   - 사람이 쓴 것처럼 약간의 변주
